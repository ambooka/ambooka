# Nexus study-resource coverage

The Nexus tracker has an explicit learning plan for every execution entry:

- S01–S24
- D1–D3

Each plan must include:

1. A watchable video or structured course.
2. Core reading or a structured course.
3. At least one implementation reference or practice resource.

Resources are shown only for the currently selected mission inside the Nexus main content area. There is no global resource drawer or separate library view.
